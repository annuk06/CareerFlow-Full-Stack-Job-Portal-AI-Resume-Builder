# CareerFlow — Full-Stack Job Portal + AI Resume Builder

CareerFlow is a modern, production-ready career management platform and job portal. It features candidate authentication, a detailed profile manager, an AI resume parser (extracting text from uploaded PDF/DOCX files), an interactive live resume builder with multiple PDF templates, a search/filter-enabled job board, a calendar scheduler, notifications, an application status tracker (Kanban + Table views), and a comprehensive Admin Panel.

This project is built to run out-of-the-box using a **hybrid database adapter** that works with local MongoDB or falls back to a JSON-file-based database system.

---

## 🏗️ System Architecture

*   **Frontend**: React (Vite) + Tailwind CSS v3 + Lucide Icons + Recharts
*   **Backend**: Node.js + Express.js + Multer (file uploads) + PDF/DOCX Text Extractor (`pdf-parse`, `mammoth`)
*   **Database**: MongoDB (Mongoose) with an automatic JSON-file fallback under `backend/data/` if MongoDB is down or not installed.
*   **Authentication**: JWT (JSON Web Tokens) + Bcrypt.js password hashing

---

## 🚀 Running the Application

### Prerequisites
*   Node.js (v16+) installed.
*   MongoDB installed locally (optional; if not running, the backend automatically uses JSON file storage).

### Step 1: Set up and Seeding the Backend
1.  Navigate to the `backend` folder:
    ```bash
    cd backend
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Seed the database with sample data:
    ```bash
    npm run seed
    ```
    *This populates the database with 15+ companies, 30+ jobs, calendars, and test users.*
4.  Start the backend server:
    ```bash
    npm run dev
    ```
    The backend runs on `http://localhost:5000`.

### Step 2: Set up and Launch the Frontend
1.  Navigate to the `frontend` folder:
    ```bash
    cd ../frontend
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the Vite developer server:
    ```bash
    npm run dev
    ```
    The frontend runs on `http://localhost:3000`.
